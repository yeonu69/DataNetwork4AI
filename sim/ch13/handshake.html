  1. [다음 세그먼트]를 누를 때마다 클라이언트와 서버가 세그먼트를 하나씩 주고받습니다. 연결(3개) → 데이터 → 종료(4개) 순서입니다.
  2. 표에서 플래그(SYN, ACK, FIN, PSH)와 순서 번호(seq), 확인 번호(ack)가 어떻게 바뀌는지 봅니다. 시작 번호는 매번 무작위입니다.
  3. 규칙은 하나: ack = 상대가 보낸 seq + 받은 바이트 수. 단, SYN과 FIN은 데이터가 없어도 1로 셉니다.
  4. [번호 맞히기]를 켜면 다음 세그먼트의 ack가 가려집니다. 직접 계산해 넣고 확인해 보세요.

핵심 3줄
• 연결은 SYN → SYN+ACK → ACK 세 번. 서로 자기 시작 번호(ISN)를 알리고 "잘 받았다"를 확인해야 양쪽 모두 보낼 준비가 됩니다.
• ack 번호는 "여기까지 잘 받았고, 다음엔 이 번호를 주세요"라는 뜻입니다. SYN과 FIN은 번호 1개를 차지합니다.
• 종료는 양쪽이 각자 FIN을 보내고 ACK를 받아야 해서 네 번입니다. 먼저 닫은 쪽은 TIME_WAIT에서 잠시 기다렸다가 완전히 닫습니다.
