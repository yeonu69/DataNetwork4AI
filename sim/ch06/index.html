6장 시뮬레이터

패리티와 CRC 오류 검출 시뮬레이터

이렇게 해 보세요
  1. 보낼 데이터 비트와 생성 다항식을 입력합니다(기본: 데이터 1101, 생성 다항식 1011).
  2. [CRC 계산]을 누르면 모듈로 2 나눗셈 과정과 나머지가 나옵니다.
  3. '받은 비트' 줄에서 비트를 눌러 뒤집으면 전송 중 오류가 난 것처럼 만들 수 있습니다.
  4. 패리티와 CRC가 각각 오류를 알아채는지 비교해 봅니다(1비트, 2비트 오류).

보낸 비트

받은 비트 (눌러서 뒤집기)

검사 방법받는 쪽 계산판정
짝수 패리티
CRC

핵심 3줄
• 짝수 패리티는 1의 개수를 짝수로 맞추는 1비트로, 홀수 개 비트 오류만 알아챕니다.
• CRC는 데이터를 생성 다항식으로 XOR 나눗셈한 나머지를 붙여 보내고, 받는 쪽은 나머지가 0인지로 오류를 판단합니다.
• CRC는 패리티가 놓치는 2비트 오류와 연속 오류도 잡아내서 이더넷 FCS(CRC-32)에 쓰입니다.
