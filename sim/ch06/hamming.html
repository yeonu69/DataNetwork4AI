해밍 코드 오류 정정

이렇게 해 보세요
  1. 보낼 데이터 4비트를 위쪽 칸을 눌러 정합니다. 해밍(7,4) 부호는 여기에 검사 비트 3개(주황)를 붙여 7비트로 보냅니다.
  2. '전송 중' 줄에서 아무 비트나 하나 눌러 잡음으로 뒤집어 봅니다(빨강).
  3. 받는 쪽은 검사 3개를 다시 계산해 '신드롬'을 구합니다. 신드롬을 2진수로 읽은 값이 바로 틀린 비트의 위치입니다.
  4. 두 비트를 뒤집으면 엉뚱한 위치를 고쳐 버리는 것도 확인하세요. 해밍(7,4)는 1비트 오류까지만 고칩니다.
① 보낼 데이터 4비트
② 전송 중 (눌러서 비트 뒤집기)
③ 받는 쪽 검사
핵심 3줄
• 해밍 코드는 위치 1, 2, 4에 검사 비트를 두고, 각 검사 비트가 서로 다른 위치 묶음을 짝수 패리티로 지킵니다.
• 받는 쪽에서 세 검사의 실패 여부를 2진수로 읽으면(신드롬) 틀린 비트의 위치가 곧바로 나와 스스로 고칠 수 있습니다.
• 이더넷의 FCS(CRC)는 오류를 '검출'만 하고 버리지만, 메모리(ECC)와 고속 링크의 FEC는 이렇게 '정정'까지 합니다.
