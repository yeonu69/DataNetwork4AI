DHCP: DORA와 임대

이렇게 해 보세요
  1. 노트북을 하나씩 켭니다([노트북 켜기]). 주소가 없는 노트북이 Discover → Offer → Request → Ack 네 번의 대화로 주소를 빌립니다.
  2. 오른쪽 주소 풀(.100~.105, 6개)에서 빌려준 주소와 남은 임대 시간이 표시됩니다.
  3. [시간 +30분]을 눌러 시간을 흘려 보세요. 임대 시간의 50%(T1)가 되면 노트북이 스스로 갱신하고, 꺼진 노트북의 주소는 만료되어 풀로 돌아갑니다.
  4. 노트북을 7대 켜서 풀이 바닥나면 어떻게 되는지(169.254.x.x 자동 주소) 확인합니다.
임대 시간 2시간
DHCP 서버(공유기)의 주소 풀
핵심 3줄
• DHCP는 주소가 없는 단말이 브로드캐스트로 "주소 주세요"(Discover)를 외치면, 서버가 제안(Offer)하고, 단말이 요청(Request), 서버가 확정(Ack)하는 4단계입니다.
• 주소는 '임대'입니다. 임대 시간의 절반(T1)에 갱신을 시도하고, 갱신하지 않은 주소는 만료되어 다른 단말에게 다시 빌려줍니다.
• Ack에는 IP뿐 아니라 마스크, 게이트웨이, DNS 서버까지 들어 있어 사용자는 아무것도 설정하지 않아도 됩니다.
