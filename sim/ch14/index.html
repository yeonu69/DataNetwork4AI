DNS 이름 풀이 시뮬레이터

이렇게 해 보세요
  1. 찾을 도메인 이름을 고르고 [이름 풀기]를 누릅니다.
  2. 내 PC → 리졸버 → 루트 → TLD(.com, .kr) → 권한 서버 순서로 질문이 오가는 과정을 기록 창에서 봅니다.
  3. 같은 이름을 한 번 더 풀어 보세요. 리졸버 캐시에 남아 있어 훨씬 빨리 답이 옵니다.
  4. www.test.com처럼 CNAME(별명)이 있는 이름은 한 번 더 찾아가는 것도 확인합니다.
걸린 시간- 답-
리졸버 캐시
핵심 3줄
• DNS는 이름을 IP 주소로 바꿔 주는 분산 전화번호부로, 루트 → TLD → 권한 서버 순서로 찾아갑니다.
• PC는 리졸버(예: 168.126.63.1)에 한 번만 묻고, 리졸버가 대신 여러 서버를 돌아다닙니다(재귀 질의).
• 답은 TTL 동안 캐시에 남으므로, 두 번째부터는 몇 ms 만에 답이 옵니다.
