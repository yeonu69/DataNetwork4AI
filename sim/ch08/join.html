8장 시뮬레이터

Wi-Fi 연결 3단계

이렇게 해 보세요
  1. 노트북에서 Wi-Fi 이름(SSID)을 눌러 접속할 때 실제로 오가는 메시지를 순서대로 봅니다. [한 단계]를 누를 때마다 화살표가 하나씩 그려집니다.
  2. 메시지는 ① 찾기(스캔) ② 인증·연결 ③ 암호 키 만들기(WPA2/3) ④ IP 받기(DHCP) 네 묶음으로 색이 나뉩니다.
  3. [비밀번호 틀림]을 체크하고 다시 해 보면 어느 단계에서 실패하는지 확인합니다.
  4. [숨긴 SSID]를 체크하면 비콘 대신 노트북이 먼저 이름을 불러 찾는(프로브) 방식으로 바뀝니다.
핵심 3줄
• Wi-Fi 연결은 '찾기 → 인증·연결 → 키 만들기 → IP 받기' 순서입니다. 앞의 셋은 2계층(무선 링크), 마지막 DHCP는 3계층 이야기입니다.
• 비밀번호는 공중으로 보내지 않습니다. 4-way 핸드셰이크에서 서로 같은 비밀번호로 만든 값이 맞는지만 확인합니다.
• "Wi-Fi는 연결됐는데 인터넷이 안 돼요"는 대개 마지막 IP 받기(DHCP) 단계의 문제입니다.
