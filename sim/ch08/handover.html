8장 시뮬레이터

셀룰러 핸드오버

이렇게 해 보세요
  1. [출발]을 누르면 휴대폰을 든 자동차가 기지국 A, B, C 옆을 지나갑니다. 위쪽 그래프는 각 기지국의 신호 세기입니다.
  2. 휴대폰은 지금 기지국보다 옆 기지국이 '여유값(히스테리시스)'만큼 더 세지면 기지국을 바꿉니다(핸드오버, 주황 세로선).
  3. 여유값을 0 dB로 내려 보세요. 경계에서 신호가 출렁일 때마다 A↔B를 오가는 핑퐁이 생깁니다.
  4. 여유값을 너무 크게(10 dB) 하면 핸드오버가 늦어져 신호가 약한 구간을 오래 버티게 되는 것도 비교합니다.
핸드오버 횟수0 핑퐁0 약한 신호(-95 dBm 미만) 구간0%
핵심 3줄
• 핸드오버는 이동 중인 단말이 연결을 끊지 않고 더 좋은 기지국으로 옮겨 가는 절차입니다. 단말이 신호를 재서 보고하고, 망이 결정합니다.
• 경계에서는 신호가 출렁이므로 "조금 더 세면 바로 옮기기"는 A↔B 핑퐁을 일으킵니다. 그래서 여유값과 대기 시간을 둡니다.
• 여유값이 너무 크면 약한 신호를 오래 붙잡아 끊길 위험이 커집니다. 적당한 값 찾기가 이동통신망 튜닝의 핵심입니다.
